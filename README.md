# LiftLibrary 🏋
A visual catalog and reference library for exploring exercises, proper form, and movement techniques.


>  **Work in Progress:** Currently built as a reference viewer, with more features planned as the project grows.

## Features
- **Exercise Directory:** Search and browse exercises by muscle group or movement.
- **Form & Mechanics:** Quick visual breakdowns and execution steps for each exercise.

## Future Plans
- [ ] Expanded exercise database & variations
- [ ] Equipment filters (barbell, dumbbell, bodyweight, etc.)
